# News 블로그형 CRUD (TipTap + Supabase + Storage) 작업 계획

## 목표

공개 News를 정적 상수에서 Supabase 동적 콘텐츠로 전환하고, TipTap 에디터 기반 관리자 CRUD(본문 JSON 저장 + 서버 새니타이즈 렌더 + 이미지 업로드)를 구현한다.

## 범위

- **레이어/슬라이스**
  - `features/news/` (신규): `api/`(getter 2 + Server Actions 4 + tag 상수), `model/`(zod schema + types), `ui/`(NewsEditor, NewsForm, 관리 목록 테이블)
  - `views/support-news/` (신규): 공개 리스트 UI, 공개 상세 UI(본문 서버 렌더)
  - `app/(marketing)/support/news/page.tsx`, `[slug]/page.tsx` — features/news getter로 배선
  - `app/(admin)/console/(dashboard)/news/page.tsx`(스캐폴드 교체) + `news/new/page.tsx` + `news/[id]/edit/page.tsx`
  - `shared/lib/news.ts` — features/news로 데이터 seam 이전(호출부 최소 변경). NewsItem에 excerpt/coverImageUrl/body 추가.
- **Supabase 스키마 변경: 있음** — `news` 테이블 + RLS + `news-images` Storage 버킷 + seed(기존 3건)

## 확립된 패턴 (company-info 확장)

- 서버 getter: `unstable_cache` + `cacheTag('news')` 태그, anon 서버 클라(no-op 쿠키), 미연결/에러 시 fallback(빈 목록/notFound). company-info의 `getCompanyInfo.ts`/`companyInfoTag.ts` 구조를 그대로 참고.
- Server Action: `createServerSupabaseClient()` → `getUser()` 인가 → DB 반영 → `revalidateTag('news','max')` + `revalidatePath`. service_role 금지.
- 배럴 유출 경계: `features/news/index.ts`는 서버 컴포넌트에서만 소비. 클라 컴포넌트(NewsEditor/NewsForm)는 model/Server Action을 하위 파일에서 직접 import.
- revalidateTag는 Next 16 시그니처 `revalidateTag(tag, 'max')` (두번째 인자 필수).

## 위임 순서

1. **supabase-agent** — `supabase/migrations/{ts}_news.sql`(테이블+RLS+news-images 버킷+seed 3건) + `plans/20260707-news-schema.md` 계약.
2. **implementer** — TipTap/새니타이저 설치(orchestrator 승인 완료), getter 스왑+fallback, 공개 리스트/상세 배선(상세 본문 서버 generateHTML+새니타이즈), 관리자 CRUD(Server Actions·에디터·폼·이미지 업로드·라우트 3개).
3. **design** — 공개 News 리스트(카드 그리드: 커버 썸네일·제목·발췌·날짜, 반응형)/상세(prose 타이포) UI/UX + 에디터/관리 폼 마크업·토큰.
4. **reviewer** — RLS·인가·service key·XSS 새니타이즈·배럴 유출·FSD·토큰·published 필터·Storage 정책 검토.

## npm 설치 (orchestrator 승인 완료)

- 에디터: `@tiptap/react @tiptap/pm @tiptap/starter-kit @tiptap/extension-image @tiptap/extension-link`
- 서버 JSON→HTML: `@tiptap/html` (generateHTML)
- 새니타이즈: `isomorphic-dompurify`
- 설치 전 최신 호환 버전 확인(React 19 / Next 16). 설치 후 package.json 커밋.

## 규칙

- RLS 필수, 공개 select는 published=true(anon)만·authenticated 전체. insert/update/delete authenticated.
- Storage `news-images` public 버킷: read 공개, write authenticated. service_role 클라 노출 금지.
- 리치텍스트 XSS 새니타이즈 필수: JSON 저장, 서버 렌더 시 generateHTML→새니타이즈.
- FSD 정방향, 슬라이스 index.ts, 서버/클라 배럴 분리. 토큰 하드코딩 0, any 금지, Props interface.
- 마이그레이션 미적용/미연결에서도 fallback으로 빌드/렌더 정상.
